# formularioImg

Práctica de procesamiento de formularios en PHP con subida de imagen.

- `index.php`: con GET muestra el formulario; con POST procesa y muestra los datos del jugador.
- `captura.html`: formulario del jugador (validación en el cliente: solo PNG de 10 KB como máximo).
- `calavera.png`: imagen que se muestra si no se sube imagen o si hay un error.
- `uploads/`: carpeta donde se guardan las imágenes subidas (necesita permisos de escritura).
